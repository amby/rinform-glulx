# Покрытие тестами

Это статическое сопоставление действий из `library/RussiaG.h` и связанного поведения русской библиотеки с транскриптами в `tests/_Tests/`.

Действие считается **покрытым**, если активная команда `>` в файле `.test` разбирается в это действие (или указанная ситуация проверяется в транскрипте). Закомментированные команды не считаются покрытием.

В колонке «Примечания» у покрытых действий перечислены **уникальные** команды из транскриптов. Закомментированные `>` не входят в список.

Последняя сверка с набором тестов: 2026-09-25.

## Сводка

| Область | Статус |
|---|---|
| Игровые глаголы в `RussiaG.h` | В основном покрыты в `test.test` и `walking.test`. |
| Повседневные мета-команды (`имена`, `счёт`, `опис`, `проверка`, `места`, `предметы`, извещения о счёте) | Покрыто (`test`, `scoring`). |
| Сессионные мета-команды (выход, рестарт, сохранение, загрузка, транскрипт, запись) | Частично: `system.test` — версия, сохранение, загрузка; выход/рестарт/транскрипт по-прежнему не покрыты. |
| Отладочная `мета!` | Не покрыто. |
| Вопросы уточнения | Не покрыто. |
| Падежные парадигмы | Частично: `declension.test` — мн. ч. вин. (animate m/f/n, inanimate m/f/n); остальное — внутри других транскриптов. |
| Числительные | Не покрыто. |

## Как обновлять

1. Добавьте или измените файл `_Tests/*.test`.
2. Отметьте соответствующее действие или ситуацию ниже и допишите команды в «Примечания».
3. Синхронизируйте дату в начале файла.

Не считайте покрытием `$WARN_UNUSED_ROUTINES` и успешную компиляцию без ошибок.

## Обозначения

| Метка | Значение |
|---|---|
| да | Хотя бы одна активная команда доходит до этого действия. |
| частично | Действие достигается, но проверяются не все строки грамматики и не все ветки `LanguageLM`. |
| нет | Активного теста нет. |
| закомментировано | Есть в файле `.test`, но закомментировано. |

Файлы: `test` = `_Tests/test.test`, `walk` = `_Tests/walking.test`, `amb` = `_Tests/ambiguity.test`, `meta` = `_Tests/basic_meta_verbs.test`, `score` = `_Tests/scoring.test`, `system` = `_Tests/system.test`, `decl` = `_Tests/declension.test`.

## Предлагаемый порядок заполнения

Пробелы, которые совпадают с `tests/README.md` и этим инвентарём, по порядку:

1. Уточнения (`Что имеется в виду` и ответ на вопрос).
2. Вывод падежей (`мета форм` или равносильные фразы).
3. Числительные (слова на вводе и окончания на выводе).
4. Отладочная `мета!` (начать с `форм`, `объект`, `обл`).
5. Оставшиеся пропуски: отладочная `мета!`, уточнения, числительные, `fem_grammar`, беглая гласная, ветки Take n=4–13.
6. Сессионные мета-команды без покрытия: выход/рестарт (да/нет), транскрипт и запись команд.
